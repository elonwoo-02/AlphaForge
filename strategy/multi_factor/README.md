## 1. 系统概述

### 1.1 整体架构

```
QMT 数据源
    │
    ▼
stock_fina_download_QMT.py    ← 下载全市场财务数据
    │
    ▼
data/stock_fina_pool_QMT.csv  ← 5154 只股票最新一期财务指标
    │
    ├──► stock_fina_screen_QMT.py            ← 筛选1：绝对阈值
    │        └──► stock_fina_selected_QMT.csv
    │
    └──► stock_fina_screen_industry_QMT.py   ← 筛选2：行业打分
             ├──► stock_fina_selected_QMT_industry.csv
             └──► industry_viz/*.png（可视化）
```

### 1.2 两种筛选方法

| 维度 | 筛选1（绝对阈值） | 筛选2（行业打分） |
|------|------------------|-------------------|
| 方法 | 5 层漏斗 + 固定阈值 | 行业内部排名换算 1~5 分 |
| 特点 | 简单直接，跨行业统一标准 | 考虑行业差异，行业中性化 |
| 适用 | 初筛 / 全市场好公司 | 同业内找龙头 |
| 输出 | `stock_fina_selected_QMT.csv` | `stock_fina_selected_QMT_industry.csv` |

### 1.3 输出文件

| 文件 | 说明 |
|------|------|
| `data/stock_fina_pool_QMT.csv` | 全市场 5154 只股票最新一期财务指标（含名称、行业）|
| `data/stock_fina_selected_QMT.csv` | 筛选1 结果（绝对阈值）|
| `data/stock_fina_selected_QMT_industry.csv` | 筛选2 结果（行业打分）|
| `data/industry_viz/*.png` | 各行业指标分布可视化图（需 matplotlib）|

## 2. 脚本说明

### 2.1 `stock_fina_download_QMT.py` — 数据下载

从 QMT 下载沪深 A 股全量财务数据，提取核心指标。

**运行前提：**
- 已启动 miniQMT 客户端
- 已安装 xtquant（`pip install xtquant`）

**使用方法：**
```bash
python stock_fina_download_QMT.py
```

**可配置项：**

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `NUM_WORKERS` | 8 | 并发下载线程数 |
| `SECTOR` | `'沪深A股'` | 股票池板块 |
| `DATA_START` | `'20150101'` | 财务数据起始日期 |
| `DATA_END` | 今日 | 自动使用当天日期 |

**提取的财务指标：**

| 类别 | 指标 | 来源表 |
|------|------|--------|
| 盈利能力 | eps, bps, roe, roa, grossprofit_margin, netprofit_margin | PershareIndex / Income |
| 偿债能力 | debt_to_assets, current_ratio, quick_ratio | Balance |
| 营运能力 | assets_turn | 营收 / 总资产 |
| 现金流 | operating_cashflow, ocf_to_revenue, ocf_to_profit | CashFlow |
| 成长能力 | netprofit_yoy | 年报净利润同比 |

### 2.2 `stock_fina_screen_QMT.py` — 筛选1（绝对阈值）

使用 5 层漏斗，按固定数值门槛筛选达标股票。

**筛选条件：**

| 层 | 条件 | 阈值 |
|----|------|------|
| 1 | ROE | ≥ 15% |
| 2 | 净利润同比 | ≥ 10% |
| 3 | 毛利率 | ≥ 30% |
| 4 | 资产负债率 | ≤ 60% |
| 5 | 经营现金流/营收 | ≥ 10% |

**可配置项：**

| 常量 | 默认值 | 说明 |
|------|--------|------|
| `ROE_MIN` | 15 | ROE 下限（%）|
| `NETPROFIT_YOY_MIN` | 10 | 净利润同比下限（%）|
| `GROSSPROFIT_MARGIN_MIN` | 30 | 毛利率下限（%）|
| `DEBT_TO_ASSETS_MAX` | 60 | 资产负债率上限（%）|
| `OCF_TO_REVENUE_MIN` | 10 | 经营现金流/营收下限（%）|

### 2.3 `stock_fina_screen_industry_QMT.py` — 筛选2（行业打分）

按行业内部排名将各指标换算为 1~5 分，5 项总分达标即入选。

**打分规则：**

| 行业内排名 | 得分 |
|------------|------|
| 前 20% | 5 分 |
| 20%~40% | 4 分 |
| 40%~60% | 3 分 |
| 60%~80% | 2 分 |
| 后 20% | 1 分 |

**打分指标：** ROE、净利润同比、毛利率、经营现金流/营收、资产负债率（低分加分）

**总分范围：** 5~25，默认筛选条件 ≥ 18

### 2.4 运行流程

```bash
# 第一步：下载数据
python stock_fina_download_QMT.py

# 第二步A：绝对阈值筛选
python stock_fina_screen_QMT.py

# 第二步B：行业打分筛选
python stock_fina_screen_industry_QMT.py
```

> 两步筛选可独立运行，也可按需求只执行其一。筛选前需确保第一步已生成 `stock_fina_pool_QMT.csv`。

## 3. 财务指标如何指导量化交易

> 💭 **Thinking：财务指标如何指导量化交易？**
>
> 作用是筛选标的和构建因子。

- **选股**：从几千只股票中，用财务指标筛出好公司
- **择时 / 加权**：根据财务指标的变化趋势，决定买入 / 卖出 / 调整仓位

> 💭 **Thinking：这些财务指标，在实战中，哪些最重要？**

### 3.1 核心指标详解

#### 3.1.1 关键指标概览

| 优先级 | 指标 | 作用 |
|---|---|---|
| ⭐⭐⭐ | ROE（净资产收益率） | 选股之王 |
| ⭐⭐⭐ | 营收 / 净利润增长率 | 成长性判断 |
| ⭐⭐⭐ | 毛利率（grossprofit_margin） | 护城河指标 |
| ⭐⭐ | 资产负债率（debt_to_assets） | 风险控制 |
| ⭐⭐ | 经营现金流（operating_cashflow） | 盈利质量 |
| ⭐ | 总资产周转率（assets_turn） | 经营效率 |

#### 3.1.2 ROE（净资产收益率）—— 选股之王

> 公司用股东的钱赚了多少利润。巴菲特最看重的指标。ROE 持续 > 15% 的公司，长期来看大概率是好公司。

$$\text{ROE} = \frac{\text{净利润}}{\text{净资产}} \times 100\%$$

```python
# 获取贵州茅台全部报告期的财务指标（QMT）
df = extract_indicators('600519.SH')

# 策略：ROE 连续 8 期（2 年）都 > 15% => 优质公司
if df.tail(8)['roe'].dropna().min() > 15:
    print("ROE 连续 2 年 > 15%，是优质公司")
```

> **注意**：单看一期 ROE 没意义，要看连续性（至少 2 年）。
>
> QMT 中 ROE 来自 `PershareIndex` 表的 `du_return_on_equity` 字段。

#### 3.1.3 营收 / 净利润增长率 —— 成长性判断

> 和去年同期比，赚钱的速度是快了还是慢了。股价本质反映的是预期——持续高增长的公司，市场会给高估值。增速下滑，即使还在赚钱，股价也可能跌。

```python
# QMT 不直接提供同比增长率，需自己用年报数据计算
annual = df[df['end_date'].str.endswith('1231')]  # 只取年报
annual['netprofit_yoy'] = annual['net_profit'].pct_change() * 100

# 策略：净利润增速连续加速（每期比上期增速更高）
annual['growth_accel'] = annual['netprofit_yoy'].diff()
if annual['growth_accel'].tail(3).min() > 0:
    print("净利润增速连续加速，考虑买入")
```

| 条件 | 含义 |
|---|---|
| 净利润同比 > 30% 且 营收同比 > 20% | 高成长 |
| 净利润增速 > 营收增速 | 盈利质量在提升（成本控制好） |
| 净利润增速 < 营收增速 | 增收不增利，警惕 |

#### 3.1.4 毛利率 —— 护城河指标

> 高毛利率意味着定价权（护城河）。毛利率持续下滑，说明竞争加剧或成本失控。

$$\text{毛利率} = \frac{\text{营收} - \text{成本}}{\text{营收}} \times 100\%$$

```python
# 策略：毛利率近 1 年下滑超过 3 个百分点 => 预警
gpm_change = df['grossprofit_margin'].iloc[-1] - df['grossprofit_margin'].iloc[-4]
if gpm_change < -3:
    print(f"警告：毛利率下降 {abs(gpm_change):.1f} 个百分点，竞争力可能减弱")
```

| 行业 | 毛利率范围 | 含义 |
|---|---|---|
| 白酒 / 医药 / 软件 | 60% ~ 90% | 高护城河 |
| 制造业 / 零售 | 15% ~ 30% | 竞争激烈 |
| 其他 | < 15% | 基本是苦生意 |

#### 3.1.5 资产负债率 —— 风险控制

> 负债率过高的公司，遇到经济下行容易暴雷。量化交易中用来排雷。

$$\text{资产负债率} = \frac{\text{总负债}}{\text{总资产}} \times 100\%$$

```python
# 排雷策略：任一条件命中即排除
latest = df.iloc[-1]
if (latest['debt_to_assets'] > 70      # 负债率 > 70%
    or latest['current_ratio'] < 1.0    # 流动比率 < 1
    or latest['operating_cashflow'] < 0):  # 经营现金流为负
    print("高风险，加入排雷名单")
```

##### 判断要点

- 非金融行业：负债率 > 60% 需警惕，> 70% 高危
- 金融 / 地产行业天然高负债（80%+ 属正常），不适用此规则
- 需结合 `current_ratio`（流动比率）一起看，负债率高但流动比率 > 2 尚可接受

#### 3.1.6 经营现金流 —— 盈利质量

> 净利润可以通过会计手段调节，但现金流很难造假。**现金流是利润的验钞机。**

```python
latest = df.iloc[-1]

# 经营现金流 / 营收 > 15% => 收现能力好
# 经营现金流 / 净利润 > 1  => 利润含金量高（赚的钱都收回来了）
if latest['ocf_to_revenue'] > 15 and latest['ocf_to_profit'] > 1:
    print("现金流质量好，盈利含金量高")
```

| 条件 | 含义 |
|---|---|
| `ocf_to_revenue` > 15% | 现金流健康 |
| `ocf_to_profit` > 1 | 利润含金量高 |
| 连续 2 年经营现金流为负 | 强烈警告，远离 |

#### 3.1.7 总资产周转率 —— 经营效率

> 公司用 1 元资产能产生多少营收。同样的毛利率，周转率高的公司赚钱更快。

#### 杜邦分析

$$\text{ROE} = \text{净利率} \times \text{周转率} \times \text{杠杆倍数}$$

| ROE 来源 | 质量评价 |
|---|---|
| 靠净利率高 | ✅ 好（有定价权） |
| 靠周转率高 | ✅ 好（经营效率高） |
| 靠杠杆高 | ⚠️ 危险（借钱撑起来的） |

#### 以贵州茅台为例

- 净利率 ~50%，周转率 ~0.35，负债率 ~21%（杠杆 1.27x）
- ROE = 50% × 0.35 × 1.27 = **22.2%**
- 主要靠超高净利率，不靠杠杆 → **质量非常高**

### 3.2 财务指标在量化中的常见用法

| 用法 | 核心指标 | 说明 |
|---|---|---|
| 选股入池 | ROE、毛利率、负债率 | 从几千只股票中筛出基本面好的候选池 |
| 财务排雷 | 负债率、流动比率、现金流 | 排除可能暴雷的公司 |
| 成长股筛选 | 净利润同比、营收同比 | 找增速快且加速的公司 |
| 价值股筛选 | ROE、BPS、EPS | 结合 PE/PB 找被低估的好公司 |
| 因子构建 | ROE、毛利率、周转率 | 作为多因子模型的 Alpha 因子 |
| 风险控制 | 负债率、速动比率、现金比率 | 控制持仓组合的整体风险 |
| 行业对比 | 毛利率、周转率、ROE | 同行业内横向对比，找龙头 |
| 趋势跟踪 | 各指标的环比 / 同比变化 | 财务指标恶化 => 减仓 / 卖出信号 |

### 3.3 实战注意事项

#### 3.3.1 财务指标有滞后性

财务报表按季度发布（一季报 4 月底、半年报 8 月底、三季报 10 月底、年报次年 4 月底），等你看到数据时已是 1~4 个月前的事。因此：

- ❌ 不适合做短线交易（日内 / 周级别）
- ✅ 适合做中长线选股（月度 / 季度调仓）
- 建议每季度财报发布后调仓一次

#### 3.3.2 不同行业标准不同

同一个指标，在不同行业的正常值差异很大：

| 指标 | 白酒 / 医药 | 银行 / 保险 | 制造业 | 互联网 |
|---|---|---|---|---|
| ROE | 20 ~ 35% | 10 ~ 15% | 8 ~ 15% | 15 ~ 30% |
| 毛利率 | 60 ~ 90% | 不适用 | 15 ~ 30% | 50 ~ 80% |
| 负债率 | 20 ~ 40% | 85 ~ 95% | 40 ~ 65% | 20 ~ 50% |
| 周转率 | 0.3 ~ 0.5 | 不适用 | 0.8 ~ 1.5 | 0.5 ~ 1.0 |

> 量化策略中，应在**同行业内对比**，而非跨行业比较。

#### 3.3.3 单一指标不可靠

任何单一指标都可能被优化或具有误导性：

| 表面信号 | 潜在风险 | 交叉验证方式 |
|---|---|---|
| 高 ROE | 可能靠高杠杆（危险） | 结合负债率看 |
| 高增长 | 可能是一次性收入（卖资产） | 结合扣非净利润看 |
| 低负债 | 可能是因为不投入（不增长） | 结合增长率看 |

> **核心思想**：永远用多个指标交叉验证 → 多因子模型的本质。

#### 3.3.4 财务数据 + 行情数据结合效果更好

最佳实践是**财务面 + 技术面结合**：

- 用财务指标选出好公司（股票池）
- 用技术指标选择好时机（买卖点）

**组合策略示例：**

| 条件 | 操作 |
|---|---|
| 负债率 > 70% | ❌ 直接排除，不参与 |
| 经营现金流连续为负 | ❌ 直接排除，不参与 |
| ROE > 15% + MACD 金叉 | ✅ 买入 |
| 毛利率 > 30% + 股价站上 20 日均线 | ➕ 加仓 |

### 3.4 多因子选股

通过多个财务指标组合筛选，从全市场股票中选出基本面优良的标的。

**核心逻辑：**

> 高盈利 + 高增长 + 高毛利 + 低负债 + 强现金流 = 好公司

| 类别 | 指标 | 来源 / 计算 |
|---|---|---|
| 盈利能力 | roe, roa, grossprofit_margin, netprofit_margin | PershareIndex / 利润表 |
| 偿债能力 | debt_to_assets, current_ratio, quick_ratio | 资产负债表 |
| 营运能力 | assets_turn | 营收 / 总资产 |
| 现金流 | operating_cashflow, ocf_to_revenue, ocf_to_profit | 现金流量表 |
| 成长能力 | netprofit_yoy | 年报净利润 pct_change 计算同比 |

#### 3.4.1 行业中性化打分

> 💭 **Thinking：这种筛选方式有什么问题？**
>
> 没有考虑行业的特点，不同行业的 ROE、利润率正常值差异很大。

解决办法：基于**行业内部排名**进行打分，实现行业中性化。

**打分规则：**

| 行业内排名 | 得分 |
|---|---|
| 前 20% | 5 分 |
| 20% ~ 40% | 4 分 |
| 40% ~ 60% | 3 分 |
| 60% ~ 80% | 2 分 |
| 后 20% | 1 分 |

**选用 5 个指标：**

1. ROE
2. 净利润同比
3. 毛利率
4. 资产负债率
5. 经营现金流 / 营收

> 每个指标各得 1~5 分，总分范围 **5 ~ 25**。筛选条件：总分 ≥ `SCORE_MIN`（默认 18）。

#### 3.4.2 不同行业 ROE 差异的原因

> 💭 **Thinking：为什么不同行业的 ROE 差异很大？**
>
> 因为不同行业赚钱的驱动力不同：

| 驱动模式 | 代表行业 | 核心特征 |
|---|---|---|
| **高销售净利率（茅台模式）** | 医药、食品 | 靠品牌溢价，高毛利率 |
| **高资产周转率（沃尔玛模式）** | 零售、贸易 | 靠薄利多销，高周转 |
| **高权益乘数 / 杠杆（银行模式）** | 银行、地产 | 靠借钱生钱，高杠杆 |

### 3.5 四大行业选股策略详解

#### 3.5.1 金融与地产（高杠杆、高 ROE）

| 项目 | 内容 |
|---|---|
| **代表行业** | 银行、非银金融、房地产 |
| **数据特征** | 资产负债率极高（62% ~ 92%），但 ROE 往往不错（银行 ~7.28%） |

> 💭 **Thinking：为什么这样？**
>
> **银行 / 保险**：负债其实是客户的存款或保费，这是它们的"原材料"。负债率高是商业模式决定的，不是风险（除非坏账爆发）。
>
> **房地产**：典型的资金密集型，靠借贷拿地盖楼。

> 💭 **Thinking：选股策略（看什么指标）？**
>
> ❌ 避坑：别看资产负债率（没意义）、别单纯看 PE（失真）

**核心指标：**

| 指标 | 说明 |
|---|---|
| **PB（市净率）** | 金融股最核心的估值指标 |
| **股息率（Dividend Yield）** | 银行股通常作为防御性资产，分红很重要 |
| **不良贷款率 / 拨备覆盖率** | 银行专用，衡量资产质量 |
| **NAV（净资产价值）** | 地产专用，衡量手里地皮的真实价值 |

#### 3.5.2 大消费与医药（高毛利、低负债）

| 项目 | 内容 |
|---|---|
| **代表行业** | 食品饮料、医药生物、家用电器 |
| **数据特征** | 毛利率极高（38% ~ 48%），负债率低，现金流好 |

> 💭 **Thinking：为什么这样？**
>
> 典型的品牌壁垒行业。恒瑞医药（医药）之所以毛利高，是因为有**专利保护**；贵州茅台（食品）之所以毛利高，是因为**品牌溢价**。

**核心指标：**

| 指标 | 说明 |
|---|---|
| **GPM（毛利率）稳定性** | 越高越好，且不能剧烈波动 |
| **ROE 稳定性** | 消费股是长跑冠军，找 ROE 连续 3~5 年维持在 15%~20% 以上的公司 |
| **销售费用率** | 注意看为了维持高毛利，公司是否烧了太多钱在广告上 |
| **PEG（市盈率相对盈利增长比率）** | 既然给高估值，必须有高增长匹配 |

#### 3.5.3 周期与制造（低毛利、重资产）

| 项目 | 内容 |
|---|---|
| **代表行业** | 钢铁、有色金属、化工、交通运输、建筑 |
| **数据特征** | 毛利率低（7% ~ 17%），ROE 波动大 |

> 💭 **Thinking：为什么这样？**
>
> **同质化竞争**：你的钢材和他的钢材没区别，只能拼价格。
>
> **重资产**：机器设备折旧大，一旦停工亏损严重。

> 💭 **Thinking：选股策略（看什么指标）？**
>
> ❌ 避坑：别在 PE 高的时候买（那是周期底部），别在 PE 低的时候买（那是周期顶部）——**PE 要反向使用**

**核心指标：**

| 指标 | 说明 |
|---|---|
| **PB-ROE 剪刀差** | 行业复苏初期，寻找低 PB 但 ROE 开始抬头的公司 |
| **存货周转率** | 谁卖得快，谁就能活下来 |
| **大宗商品价格** | 外部因子，如铜价涨 → 有色股才能涨 |
| **经营现金流（OCF）** | 虽然毛利低，但收进来的都是真金白银，适合做防守仓位 |

#### 3.5.4 TMT 与科技（高成长、轻资产）

| 项目 | 内容 |
|---|---|
| **代表行业** | 计算机、电子、传媒、通信 |
| **数据特征** | 行业 ROE 整体不高，但个股分化极大（如满分股瑞芯微） |

> 💭 **Thinking：为什么这样？**
>
> **赢家通吃**：科技行业要么是 0，要么是 100。大量的研发费用（R&D）在前期拖累利润，导致 ROE 低；一旦技术突破，爆发力极强。

**核心指标：**

| 指标 | 说明 |
|---|---|
| **营收增速 > 利润增速** | 早期科技股看营收抢占市场 |
| **研发支出占比（R&D / Revenue）** | 衡量"未来潜力"的因子 |
| **动量因子（Momentum）** | 科技股受情绪和资金驱动，价格趋势很重要 |

#### 3.5.5 四大行业选股逻辑汇总

> 💡 不同行业需要看不同的核心指标，不能用同一套标准衡量。

| 行业 | 核心指标 | 避坑提示 |
|---|---|---|
| **金融地产** | PB、股息率、不良率（银行） | ❌ 慎用 PE、资产负债率无意义 |
| **大消费医药** | 毛利率、ROE 持续性、销售费用率、PEG | 看品牌壁垒和 ROE 稳定性 |
| **周期制造** | PB-ROE 剪刀差、存货周转率、大宗商品价格、OCF | ❌ PE 反向使用，高 PE 反而是底部 |
| **TMT 科技** | 营收增速、研发投入占比、动量因子 | 前期研发压制利润，个股分化巨大 |
