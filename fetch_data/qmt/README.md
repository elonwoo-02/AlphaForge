# QMT / miniQMT 数据采集

A 股行情与财务数据（需启动 miniQMT 客户端）。

## 脚本

| 文件 | 说明 |
|------|------|
| `daily_data_qmt.py` | 日线 OHLCV（前复权） |
| `minute_data_qmt.py` | 分钟 K 线 |
| `financial_data_qmt.py` | 综合财务指标 |

## 运行

```bash
# 1. 先启动 miniQMT 客户端并确保联网
# 2. 再运行脚本
python daily_data_qmt.py
python minute_data_qmt.py
python financial_data_qmt.py
```

## 注意事项

- 运行前必须先启动 miniQMT 客户端
- 部分下载为异步操作，需耐心等待

## QMT 工具详解

### QMT

#### 开户与权限开通时间线

按工作日计算，理想情况下的时间节点：

| 天数 | 进展 |
|------|------|
| 第 1 天 | 开户成功，出具股东账号 |
| 第 2 天 | 分配服务经理（可在【我的-帮助中心】查看） |
| 第 3 天 | APP 上显示服务经理，添加企微联系；可发起程序化交易报备 |
| 第 5 天 | 程序化交易报备完成；可发起 QMT 终端申请 |
| 第 6 天 | QMT 终端申请完成，可登录 QMT |

> 完整开通一套 QMT 程序化权限，理想状态下共 **6 个工作日**。

#### 常见问题

1. **QMT 开通后自带的免费数据包含哪些？**
   A 股行情数据和股票等基本数据均可获取，Level-2 功能和数据需单独收费。

2. **港股、期货、期权数据如何开通？费用多少？**
   - 港股不支持（仅支持港股通）
   - 期权、期货需看具体期货公司
   - 只收取交易佣金（与服务经理协商），不收开通费

3. **境外手机号可以申请开通 QMT 吗？**
   需要中国大陆手机号，境外手机号无法办理。

4. **境外可以使用 QMT 实盘或模拟盘吗？是否禁止翻墙软件？**
   - 境外无法登录 QMT，服务器在国内
   - 在国内私自使用 VPN 属于违规行为

### QMT 与 miniQMT 对比

#### 功能完整度

| 对比项 | QMT | miniQMT |
|--------|-----|---------|
| **功能** | 行情、研究、回测、实盘、风控全栈平台 | 仅保留"实盘交易 + 行情接口"极简子系统 |
| **开发语言** | Python / VBA | Python（XtQuant） |
| **运行方式** | 本地 / 云端 | 本地 Python 程序 |
| **GUI** | 有图形界面 | 无图形界面、无回测、无高级风控 |

#### 策略开发方式

| 对比项 | QMT | miniQMT |
|--------|-----|---------|
| **策略位置** | 必须写在 QMT 客户端内部 | 策略可写在任意 IDE（PyCharm、Jupyter 等） |
| **下单方式** | 客户端内置运行 | 通过 XtQuant API 将指令发回券商柜台 |
| **核心优势** | 策略与界面一体 | 策略与交易分离，开发更自由 |

#### 运行环境

| 对比项 | QMT | miniQMT |
|--------|-----|---------|
| **依赖** | 需保持 QMT 客户端打开 | 仅需后台运行轻量化代理进程 |
| **部署** | 本地 / 云端 | 可放云服务器，资源占用更少 |
| **延迟** | 正常 | 官方称订单延迟可低至 5ms |

#### 适用人群

| 对比项 | QMT | miniQMT |
|--------|-----|---------|
| **适合谁** | 私募、高净值个人；需要图形回测、多账户管理、强风控 | 量化开发者 / 爱好者；自主写 Python 策略，追求轻量化和低延迟 |
| **回测需求** | 依赖内置回测 | 自行搭建回测 |

> **💡 选型提示**：
> 1. 要做历史回测、可视化、多账户管理 → 选完整版 **QMT**
> 2. 自己写 Python 策略，想跑在云服务器，不在乎自带回测界面 → 优先 **miniQMT**

> **总结**：QMT 是**大而全的量化工作站**；miniQMT 是把交易接口抽出来的**小而快的 Python 量化利器**。
